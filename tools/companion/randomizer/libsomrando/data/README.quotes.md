# Dialogue quote data (Ancient Cave)

`sr_quotes_mitch.c` and `sr_quotes_demetri.c` hold the NPC dialogue pools of Ancient Cave mode (setting `acDialogue`). They are
generated by `tools/gen_p3_quotes.py` from `MitchHedbergQuotes.cs` and `DemetriMartinQuotes.cs` of the upstream randomizer, byte for byte.

**The quote text is third-party material and is not covered by the LGPL-2.1+ that applies to the rest of libsomrando.** It lives only in
these two files; no file under `src/` contains any of it.

## Building without the quotes

Remove the two files from your distribution (or do not ship them) and build with the placeholder pool instead:

- CMake: `-DSOMRANDO_QUOTES=OFF`
- `build.sh`: `SOMRANDO_QUOTES=0 ./build.sh lib`

`sr_quotes_placeholder.c` is original neutral text with pools of the same sizes (45 Mitch, 50 Demetri), so the event numbering does not
change. It defines `sr_quotes_are_upstream = 0`.

## What is lost

Ancient Cave ROMs built with the placeholders are valid and playable, but no longer byte-identical to the C# generator. The dialogue
events differ in their bytes and length, so every address allocated after them (the event expander output and anything placed behind it)
moves as well. With the real data (`sr_quotes_are_upstream = 1`) the output matches the C# generator for the same ROM, settings and seed.
