# Companion UI graphics pack (manifest only)

The pictures are NOT in this repository.  They are generated by `tools/companion/ux/build_assets.py` from the owner's
local Godot project into `/home/cidwel/.local/state/som-decomp/companion-20261017/assets/` and referenced by path.
The Godot project's README lists them as Square Enix stand-ins that cannot be distributed.  `som_ui_draw.c` runs
without the pack (built-in procedural frame, 5x7 font and icon shapes).

| Item | Value |
| --- | --- |
| Pack | `som_ui_pack.bin` (format `SUXP` v1, see `build_assets.py`), 512x512 RGBA atlas, 258 rects |
| Size | 1,052,716 bytes |
| sha256 | `9ed6e4e981ba03445da1ae61e97f741a3eb168f1042776d34f49d87f14992bbf` (changes if the sources change) |

Rect ids: `0x0100+ch` outlined 8x11 font glyph (the only face drawn), `0x0200+ch` small font glyph (unused), `0x1000+n` icon n of
`spr_iconsGeneral` (16x16: items 1..11, weapons 9, 20..26, spirits 27..34), `0x1100+spell id` spell icon (a cell of `spr_iconsSkills`), `0x2000+h` portrait 98x108, `0x2010+h` portrait 24x26
(h: 0 boy, 1 girl, 2 sprite).  The window frame, gauges, radar, arrows and the world map are drawn procedurally; the
world map is decoded at runtime from the user's own ROM (no map picture is stored anywhere).

Rendered PNG mocks of every mode and both screens: `<state>/ux/mocks/` (index in `index.json`).
Raw pack-less golden images: `<state>/ux/golden/*.argb`; their hashes: `tools/companion/ux/golden_hashes.txt`.

Third round (ring info, quick slots, options): the pack is unchanged (same sha256, 258 rects).  The OPT gear, the "+" of an empty slot,
the menu and submenu slot tiles and the option checkboxes are drawn procedurally; spell, spirit, weapon and item icons come from the
existing rects.
